🎨 NEW FEATURES IN v0.2.2:
===========================

1️⃣  Arbitrary Angle Rotation 🔄
   - Rotate images by ANY angle (not just 90°)
   - Smooth bilinear interpolation
   - Fast path for 90° increments
   - Example: img.rotate(45.0), img.rotate(123.5)

2️⃣  Extended Shape Drawing ⭐
   - draw_star() - Customizable star shapes
   - draw_triangle() - Triangle drawing
   - draw_polygon() - Custom polygons
   - draw_ellipse() - Ellipse/oval shapes
   - draw_regular_polygon() - Pentagon, hexagon, octagon, etc.

3️⃣  Quick Image Display 🖼️
   - img.show() - Opens in default system viewer
   - Cross-platform (Windows/macOS/Linux)
   - Perfect for quick previews during development
   - Pillow-compatible API

💻 USAGE EXAMPLES:
==================

Arbitrary Rotation:
-------------------
img = imgrs.Image.open('photo.jpg')
img = img.rotate(45.0)    # Any angle!
img = img.rotate(123.5)   # Smooth interpolation
img.save('rotated.jpg')

Extended Shapes:
----------------
canvas = imgrs.Image.new('RGB', (500, 500), 'white')
canvas = canvas.draw_star(250, 250, 150, 75, 5, (255, 215, 0, 255))
canvas = canvas.draw_triangle(100, 100, 200, 200, 150, 250, (255, 0, 0, 255))
canvas = canvas.draw_polygon([(x1, y1), (x2, y2), ...], (0, 255, 0, 255))
canvas = canvas.draw_ellipse(250, 250, 100, 50, (0, 0, 255, 255))
canvas = canvas.draw_regular_polygon(250, 250, 100, 6, (255, 0, 255, 255))
canvas.save('shapes.png')

Quick Preview:
--------------
img = imgrs.Image.open('photo.jpg')
img = img.blur(5).sharpen(2.0)
img.show()  # Opens in default viewer - instant preview!
img.save('processed.jpg')
